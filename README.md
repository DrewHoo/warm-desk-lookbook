# Warm desk lookbook

Heated desk and floor mats, under-desk radiant panels, wool arm warmers, and felt panels for a cold home office. Each item is priced per hour against a Vornado VH200 on medium (1,125 W at 28¢/kWh).

Live: https://drewhoover.com/warm-desk-lookbook/

- `data.js`: verified listings (checked in a browser on 2026-10-11)
- `copy.json`: page copy
- `template.html` + `python3 build.py` → `index.html` (self-contained page)
- `og.mjs` → `og.png` (`NODE_PATH=<dir with sharp> node og.mjs`)
